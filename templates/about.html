About Rainfall Analysis

An empirical weather science intelligence system • Created by Hemanth_Kumar

Project Overview & Leadership

Rainfall Analysis is an empirical machine learning platform engineered to forecast rainfall probabilities, evaluate precipitation risks, and visualize meteorological trends across the Indian subcontinent. Developed and created by Hemanth_Kumar, the system bridges historical climatology and modern statistical machine learning to provide actionable weather intelligence.

Official Kaggle Dataset Documentation

The application is powered by the comprehensive historical dataset published on Kaggle: Kaggle: Rainfall in India (1901–2015) by Raj Anand , sourced from the Indian Meteorological Department (IMD), Government of India.

Machine Learning Methodology & Benchmarks

1. Data Preparation & Leakage Prevention: Data is split into 80% training (39,513 records) and 20% held-out test (9,879 records) using stratified sampling. Missing values are imputed with subdivisional medians, and all transformations (scaling, one-hot encoding) are encapsulated strictly inside Scikit-Learn Pipeline objects fit exclusively on training data.

2. Algorithm Comparison: 7 classifiers are trained and benchmarked simultaneously: Gradient Boosting, Random Forest, Logistic Regression, Support Vector Machine (calibrated), Decision Tree, K-Nearest Neighbors, and Naive Bayes. XGBoost is evaluated dynamically and disclosed if not installed.

3. Class Imbalance Handling: Rainfall occurrences are naturally asymmetric across dry vs monsoon seasons. Rather than relying on misleading raw accuracy, model selection is strictly guided by the harmonic F1-score (0.8956) and ROC-AUC (0.9490).

Model Limitations & Ethical Meteorological Disclaimer

The predictions and probability estimates provided by this system are mathematical approximations generated by statistical machine learning models trained on historical observations. While highly accurate for macroscopic planning, local micro-climates, sudden low-pressure depressions, coastal cyclones, and climate change anomalies can create localized deviations. These outputs should be used for research, planning, and academic exploration, and do not replace official emergency forecasts issued by the Indian Meteorological Department (IMD).
